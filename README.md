# 절세계좌 은퇴 시뮬레이터

ISA · IRP · 연금저축에 **일반 과세계좌**까지, 계좌별로 나눠 **매년 납입 → 수익률 반영 → 다음 해로 이월**하고,
은퇴 후에는 거꾸로 인출하면서 세금까지 계산하는 연 단위 시뮬레이터입니다.

`index.html` 파일 하나로 끝납니다. 브라우저로 열면 바로 동작하고, 서버도 빌드도 외부 라이브러리도 필요 없습니다.
입력값은 브라우저 localStorage에 자동 저장되며 JSON으로 내보내고 불러올 수 있습니다.

모든 금액 단위는 **만원**입니다.

## 다루는 계좌

| 계좌 | 성격 | 기본 연 납입한도 |
|---|---|---|
| ISA | 순이익 비과세 + 초과분 9.9% 분리과세 | 2,000 |
| IRP · 투자용 | 세액공제 대상 | 300 |
| IRP · 퇴직금 수령 | 퇴직소득 재원 (퇴직소득세 적용) | 유입액 직접 입력 |
| 연금저축 · 세액공제용 | 세액공제 대상 | 600 |
| 연금저축 · 비과세용 | 세액공제 안 받음 → 인출 시 원금 비과세 | 900 |
| 일반계좌 · 직접투자 | 절세계좌 한도 밖 자금. 매년 배당과세 + 매도 시 실현이익 과세 | 없음 |

한도는 표에 경고를 띄우는 기준일 뿐 입력을 막지는 않으며, 계좌별 수익률과 함께 설정에서 바꿀 수 있습니다.

**상속금처럼 절세계좌에 담기지 않는 목돈**은 해당 연도의 「일반계좌 납입」 칸에 한 번에 넣으면 됩니다.
일반계좌는 납입한도도 인출 요건도 없어서, 은퇴가 만 55세보다 이른 경우 연금계좌를 건드리지 못하는 기간을 메우는 자금으로도 쓰입니다.

## 할 수 있는 것

- **연도별 표**에 계좌별 납입·인출만 입력하면 잔액·세금·세후 수령액이 즉시 다시 계산됩니다. 페이지 맨 위에 있어 바로 손댈 수 있습니다.
- **기초 잔액** — 이미 굴리고 있는 계좌를 **자금 성격별로** 심고 시작합니다. 같은 1억이라도 비과세 원금이냐 세액공제 원금이냐에 따라 인출 세금이 달라지므로 총액이 아니라 성격별로 넣어야 합니다.
- **남은 재원 표시** — 표에 `비과세원금 / 퇴직재원 / 과세대상` 잔액을 함께 보여줍니다.
  **연금계좌(IRP+연금저축)만 합산**합니다 — ISA 납입원금과 일반계좌 취득가를 같이 더하면 "세금 없이 뺄 수 있는 돈"이 부풀려집니다.
  일반계좌는 매도할 때 취득가와 평가익이 보유 비중대로 함께 빠져 취득가만 골라 뺄 수 없고, ISA는 비과세 한도·9.9%라는 다른 규칙을 따릅니다.
- **계좌별 재원 구성** — 표 아래에 계좌 × 재원 매트릭스가 있습니다. 어느 계좌에 어떤 성격의 돈이 얼마나 남았는지, 인출하면 무슨 세금이 붙는지 한 줄로 나옵니다.
  표에서 연도를 클릭하면 그 해로 바뀝니다.
- **적립 규칙** — 조건을 정해두면 그대로 쫙 채웁니다. 규칙마다 `기간 · 월/연 금액 · 매년 증액률 · 넣을 곳`을 정하고,
  여러 줄을 쌓으면 합쳐서 적용됩니다(적립 기본 + 중간에 목돈 한 번, 같은 조합).
  - **⭐ 우선순위대로 자동 배분** — 그해 총 투자금액을 **절세에 유리한 순서로** 알아서 나눠 담습니다.
    기본 순서는 연금저축(세액공제) → IRP 투자용 → ISA → 연금저축(비과세) → 일반계좌.
    각 계좌의 연 납입한도와 **연금계좌 합산 한도(1,800만원)** 를 지키며 채우고 남는 돈은 다음 계좌로 넘깁니다.
    순서·한도는 계좌 설정에서 바꿉니다(우선순위 0 = 배분 제외).
  - 특정 계좌 하나만 지정할 수도 있습니다 — 상속금 같은 목돈은 `2030~2030, 연 1억, 일반계좌만`.

  예를 들어 월 600만원을 우선순위 배분하면 연 7,200만원이 이렇게 갈립니다 —
  연금저축 600 + IRP 300 + 연금저축 비과세 900(합산 1,800 상한) + ISA 2,000 + 일반계좌 3,400.
- **인출 규칙** — 적립과 같은 방식으로, 규칙마다 `기간 · 월/연 금액 · 매년 증액률 · 뺄 곳`을 정합니다.
  - **계좌 지정 인출** — 찍은 계좌에서 정한 금액을 그대로 뺍니다. 순서를 직접 통제하고 싶을 때 씁니다
    (예: `2040~2060, 연 1,500만원, 연금저축 세액공제용` → 저율 구간을 매년 꽉 채워 인출).
  - **⭐ 목표 생활비** — 그 금액(세후)을 채우도록 **부족한 만큼만** 자동 배분합니다. 국민연금 세후 수령액은 목표에서 먼저 차감합니다.
  - **둘을 섞을 수 있습니다.** 계좌 지정 인출을 먼저 반영하고 목표에 모자란 부분만 자동으로 메웁니다.
    자동으로 채운 몫은 되돌리지만 **직접 지정한 금액은 깎지 않습니다** — 목표보다 많이 지정해도 그대로 유지됩니다.

  자동 배분에는 두 전략이 있습니다.

  - **연금 저율구간 우선** (기본) — 사적연금 과세대상이 분리과세 문턱(기본 1,500만원)을 넘지 않는 선까지 **연금계좌에서 먼저 뽑고**, 모자란 만큼만 ISA·일반계좌에서 채웁니다. 저율 구간은 그해 안 쓰면 사라지므로 ISA를 먼저 헐어 아껴둘 이유가 없습니다.
  - **그해 세금 최소** — 눈앞의 세금만 보고 고릅니다. 비과세인 ISA부터 몽땅 빼는 경향이 있어, 초반엔 세금이 0이지만 후반에 과세 재원만 남습니다.

  | | 그해 세금 최소 | 연금 저율구간 우선 |
  |---|---|---|
  | 세후 수령 총액 | 9.66억 | **10.3억** |
  | 총 납부 세금 | 1.14억 | **6,953만** |
  | 자산 소진 | 2067년 | **2069년** |

  어느 쪽이든 연금수령한도·만 55세 요건을 지키고, 목표를 채우지 못하는 해는 자산을 태우는 대신 부족분을 경고로 알립니다.
- **퇴직소득세 계산기** — 퇴직급여와 근속연수로 실효세율을 계산해 시뮬레이션에 적용합니다.
- **계좌 간 이전** — 계좌를 합치거나 옮기는 것은 납입이 아니라 이체라서 **연 납입한도에 걸리지 않습니다.**
  IRP 투자용을 연금저축으로 합치거나, ISA 만기 자금을 세액공제 안 받는 연금저축으로 넘길 때 씁니다.
  `시작 / 종료 / 주기`로 반복을 표현하므로 **ISA 풍차돌리기**(3년 만기를 굴리며 만기마다 전액 전환)도 한 줄로 적힙니다.
- **실질 표시 토글** — 모든 금액을 시작연도 화폐가치로 환산해 봅니다.
- 계좌별 자산 추이(누적 영역)와 은퇴 후 현금흐름(누적 막대) 차트, CSV·JSON 내보내기.

## 🎮 인생 시뮬 (턴제 모드)

상단 탭에서 전환합니다. **한 턴 = 1년**이고, 되돌리기는 한 턴만 됩니다.

플래너는 정답이 계산되는 도구입니다(자동 배분이 실제로 그걸 합니다). 게임이 되려면 미리 알 수 없어야 하고,
그걸 만드는 게 **시장 수익률의 불확실성**입니다. 매년 결정을 내린 **다음에** 그해 수익률이 공개되므로,
"IRP에 넣으면 세액공제 16.5%지만 55세까지 잠긴다" 같은 선택이 비로소 진짜 딜레마가 됩니다.

**인생 일정**은 랜덤이 아니라 직접 짜둡니다 — `이름 · 종류 · 금액 · 기간 · 주기 · 금액기준 · ±공차`.

| 종류 | 뜻 |
|---|---|
| 소득 | 그해 쓸 수 있는 세후 소득 (근로소득·연금 수령) |
| 목돈 유입 | 상속·보너스처럼 한 번에 들어오는 현금. **어디에 넣을지 직접 정합니다** |
| 퇴직금 | IRP(퇴직금 수령)에 **퇴직 재원으로 자동 유입**됩니다. 현금으로 받아 배분하는 돈이 아니라 퇴직소득세 대상입니다 |
| 지출 | 등록금·결혼 지원처럼 그해 나가야 하는 목돈 |

`금액기준`을 **물가 연동**으로 두면 금액을 시작연도 기준 실질로 보고 그해까지 불립니다 —
"26년 기준 2억"인 결혼자금이나 물가에 연동되는 국민연금이 여기 해당합니다. **명목 고정**은 금액이 그대로입니다(비과세연금 등).

`±공차`를 주면 시드에 따라 실제 연도가 앞뒤로 움직입니다. 자녀 결혼처럼 시점이 확정되지 않은 일정에 씁니다.
공차는 시드에 묶여 있어 되돌려도 흔들리지 않습니다.

「기본 계획 불러오기」를 누르면 학자금·상속·퇴직금·결혼자금·국민연금이 들어간 표본 계획이 채워집니다.
`💡` 로 시작하는 항목(건강보험료·의료비·자동차 교체·주택 수선)은 흔히 빠뜨리는 지출이라 넣어둔 추천이므로, 필요 없으면 삭제하세요.

매 턴 `소득 + 유입 − 생활비 − 지출`을 계산해 남으면 **어디에 넣을지**, 모자라면 **어디서 뺄지** 묻습니다.
「자동 배분」을 누르면 플래너의 우선순위·인출 전략을 그대로 써서 제안합니다.

**시드가 같으면 같은 시장을 만납니다.** 전략만 바꿔 다시 돌리면 순수하게 판단의 차이를 비교할 수 있습니다.
진행한 플레이는 아래 연도별 표에 그대로 기록되므로, 게임이 끝나면 플래너로 넘어가 뜯어볼 수 있습니다.

## 계산 규칙

**인출 순서 (연금계좌 공통)** — 소득세법상 순서를 그대로 따릅니다.
① 세액공제 안 받은 원금(비과세) → ② 퇴직소득 재원 → ③ 세액공제 받은 원금 + 운용수익

**연금소득세** — 만 55~69세 5.5%, 70~79세 4.4%, 80세~ 3.3%.
사적연금 과세대상 수령액이 연 1,500만원을 넘으면 전액을 16.5% 분리과세로 계산합니다(설정에서 변경 가능).

**퇴직소득 재원** — 연금으로 받으면 퇴직소득세의 70%, 연금수령 11년차부터 60%. 연금수령한도를 넘겨 받으면 100%.
단, 퇴직금을 굴려 얻은 **운용수익은 퇴직소득이 아니라 연금소득**이므로 연금소득세율이 붙습니다.

**연금수령한도** — 평가액 ÷ (11 − 연금수령연차) × 120%.
초과분은 연금외수령으로 보아 기타소득세 16.5%를 적용합니다.

**수령 요건** — 만 55세 이상 + 가입 5년 경과(퇴직금 재원 IRP는 5년 요건 없음).
미충족 인출은 전액 연금외수령으로 처리합니다.

**ISA** — 납입원금까지는 비과세 인출, 원금을 넘는 부분은 비과세 한도(일반 200만·서민형 400만) 차감 후 9.9% 분리과세.
가입 3년 미만 인출은 혜택 없이 15.4%로 계산합니다.

**세액공제** — 연금저축 600만 + IRP 합산 900만까지, 총급여 5,500만 이하 16.5% / 초과 13.2%.
환급액은 표에 표시되지만 자산에 자동 반영되지는 않습니다(재투자하려면 다음 해 납입액에 더하세요).

**퇴직소득세** — 근속연수공제 → 환산급여공제 → 기본세율 → 연분연승, 지방소득세 10% 포함.

**일반계좌 → 연금계좌** — 이것만은 이체가 아니라 **매도 후 납입**입니다.
평가익에 양도세를 물고 **세후 금액만** 들어가며, 연 납입한도와 세액공제 한도가 그대로 적용됩니다
(남은 공제 여유만큼만 공제 원금이 되고 나머지는 비과세 원금).
생활비로 뺀 돈이 아니므로 「총인출·세후수령」에는 잡히지 않습니다.
은퇴 후에도 직투 자금을 연금저축으로 계속 옮기고 싶을 때 씁니다 —
**연금저축은 연금수령 중에도 대체로 납입할 수 있지만, IRP는 연금수령을 개시하면 추가 납입이 막히는 것이 일반적**이라
그 상황이면 경고를 띄웁니다(계속 넣으려면 별도 IRP 개설).

**ISA·연금계좌 간 이전** — 납입한도와 무관하게 처리합니다.
`ISA → 연금계좌`는 전환금액의 10%(최대 300만원)를 추가 세액공제받고 그 10%만 과세 원금이 되며, 나머지는 비과세 원금으로 들어갑니다.
ISA 순이익은 비과세 한도 차감 후 9.9%가 정산됩니다.
`연금계좌끼리`는 계좌이체로 보아 자금 성격(비과세 원금·세액공제 원금·퇴직 재원·운용수익)이 그대로 따라갑니다 —
받는 계좌에서 퇴직 재원은 계속 퇴직소득세로, 세액공제 원금은 계속 연금소득세로 과세됩니다.
계좌이체 특례는 만 55세 이상 + 가입 5년 경과라야 적용되므로, 요건 전 이전은 경고를 띄웁니다.
자금 성격을 유지한다는 말은 **받는 계좌 이름과 무관하게** 세금이 따라온다는 뜻입니다 —
IRP의 세액공제 원금을 「연금저축·비과세용」으로 옮겨도 비과세가 되지 않고 계속 연금소득세 대상입니다.
퇴직급여 재원이 섞인 이체와 부분이체는 실제로 금융사에서 막힐 수 있어 경고를 띄웁니다(계산은 그대로 진행).

**일반계좌** — 과세 구조가 절세계좌들과 근본적으로 다릅니다.
배당은 인출 여부와 무관하게 **매년 15.4%가 원천징수**되고(세후 재투자로 처리),
매도할 때만 평가익이 실현되어 과세됩니다. 매도 시 원금과 평가익이 보유 비중대로 함께 빠지므로
인출액 전체가 아니라 그중 평가익 몫에만 세금이 붙습니다.
양도차익 세율은 설정한 유형을 따릅니다 — **국내주식 비과세 / 해외주식 직투 22%(연 250만원 기본공제) / 국내상장 ETF·펀드 15.4%**.

## 한계

- 세법·한도는 2026년 기준 가정입니다. 실제 제도는 바뀔 수 있습니다.
- 자동 인출 계획은 **그해의 세금만** 최소화합니다. 비과세·저율 재원을 먼저 쓰고 연금저축 잔고를 뒤로 미루는 경향이 있어,
  후반에 사적연금 수령액이 1,500만원을 넘어 16.5%가 붙기도 합니다.
  경고에 해당 연도가 뜨면 인출을 앞당겨 여러 해로 나눠 보세요 — 표에서 직접 고칠 수 있습니다.
- 수익률은 매년 일정하다고 가정합니다(변동성·수익률 순서 위험 미반영).
- 건강보험료, 종합과세 선택 시 유불리, 금융소득종합과세는 계산하지 않습니다.
  일반계좌 금융소득이 연 2,000만원을 넘으면 경고만 띄우고 세금은 15.4%로 계산하므로, 그 구간의 실제 세부담은 계산값보다 큽니다.
- 해외주식 배당의 현지 원천징수(미국 15% 등)와 국내 추가과세 차이는 15.4%로 단순화했습니다. 대주주 양도소득세도 다루지 않습니다.
- 참고용 계산기이며 세무·투자 자문이 아닙니다.
